## 2026-10-02

### 17.0 三步优化

- 第一步完成：删除 `AutomationMainlineBus`，统一使用 `AutomationTriggerBus`。
- 第二步完成：决策层使用 `AutomationActionRegistry` 校验动作，执行层统一通过 Action Provider 执行。
- 第三步完成核心清理：删除自动化状态捕获/恢复、回滚、SessionStateStore、TraceStore、TraceLogger 和执行记录 UI 依赖。
- Debug 构建通过：0 个错误、98 个警告。

### 为什么改

自动化以三层为主线：观察层发现事件，决策层判断规则，执行层完成动作。删除状态恢复和执行 Trace 后，自动化主流程更短，音频、主题、亮度等能力模块继续保留独立 UI 和底层能力。
