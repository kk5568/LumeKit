# LumeKit 需求

更新时间：2026-10-01

## 1. 项目要做什么

LumeKit 是一个运行在 Windows 上的音频管理工具，重点解决以下问题：

- 管理蓝牙音频输入和输出设备。
- 在多个音频设备之间快速切换。
- 通过快捷键切换输入、输出路由和相关音量。
- 通过系统托盘和浮层快速操作。
- 对连接、切换和自动化结果进行通知。
- 根据场景控制通知、主题、背景效果和系统效率设置。
- 通过自动化规则，在程序、系统状态或时间变化时执行动作。

## 2. 当前代码已体现的功能范围

- 主窗口、导航和多个设置页面。
- 蓝牙页面和音频设备相关服务。
- 输入音量、输出设备连接和音频路由快捷键。
- 主题、壁纸压暗、夜间模式和自动昼夜主题。
- 亮度、自动亮度和显示器相关控制。
- 电源/后台效率和触摸板控制。
- 通知服务、应用通知和托盘入口。
- 自动化规则编辑、规则保存、条件/触发器和动作执行。
- 自动化动作：通知、亮度、音量、音频设备、电源模式、程序、快捷键、触摸板、保存/恢复状态等。
- DeskBox 风格的新浮层测试实现。

## 3. 当前不应当当作已完成的内容

- 自动化架构文档中列出的所有观察源和模块都已完整实现。
- DeskBox 浮层已经完全替换旧通知、托盘面板和右键菜单。
- 所有平台架构都已经发布验证。
- 主项目和 Core 项目的 Windows App SDK 版本已经统一。
- 当前代码已经通过一次全新的本地构建验证。

## 4. 需求边界

本项目首先服务于 Windows 桌面环境，优先保证 Windows 10 19041 及以上、推荐 Windows 11 的使用体验。音频设备和系统能力不可用时，应显示可理解的失败结果，而不是让应用无提示退出。
