# LumeKit 验收标准

更新时间：2026-10-05

说明：下面只有明确标注“已验证”的项目才是通过状态，其余全部还没验证。真实设备验收按当前计划暂缓。

## 1. 构建与启动

- [x] Debug 配置可以成功生成（已验证：命令行 `dotnet build -c Debug -p:Platform=x64` 为 0 个错误、100 个警告）。
- [ ] 目标平台至少完成 x64 验证。
- [ ] 应用可以启动、打开主窗口并进入设置页面。
- [ ] 没有因为缺少蓝牙设备、摄像头或显示器能力而直接退出。

## 2. 音频功能

- [ ] 可以显示可用的蓝牙音频设备。
- [ ] 可以连接和断开设备。
- [ ] 可以区分输入和输出设备。
- [ ] 可以切换输出路由。
- [ ] 输入音量调整结果与系统实际状态一致。
- [ ] 设备不可用或操作失败时有明确提示。

## 3. 快捷键和托盘

- [ ] 快捷键可以触发配置的音频路由动作。
- [ ] 托盘图标可以正常显示、点击和退出。
- [ ] 托盘面板不会遮挡或脱离可用屏幕区域。
- [ ] 应用重启后设置仍然保留。

## 4. 自动化

- [ ] 可以创建、编辑、保存和删除自动化规则。
- [ ] 触发器和条件按预期匹配。
- [ ] 动作按配置顺序执行。
- [ ] 动作成功和失败都有明确通知或日志结果。
- [ ] 规则执行不会阻塞主界面。
- [ ] 自动化失败时可以按配置继续、重试或中止（代码已支持 Continue/Retry/Abort，但未在真机验证）。

## 5. 主题、亮度和效率

- [ ] 深色/浅色主题可以切换。
- [ ] 背景效果不可用时可以降级显示。
- [ ] 亮度功能在支持的显示器上有效。
- [ ] 自动亮度和自动昼夜主题在开启/关闭后行为正确。
- [ ] 后台效率和电源相关操作失败时有明确原因。

## 6. 通知和浮层

- [ ] 普通通知可以显示、自动关闭和手动关闭。
- [ ] 通知内容不会超出窗口。
- [ ] DeskBox 浮层测试入口可以单独验证尺寸、材质、主题和动画。
- [ ] 新浮层未正式替换旧业务前，旧通知和托盘功能不受影响。

## 7. 文档一致性

- [ ] 技术方案只描述当前已存在或明确标注为计划中的内容。（2026-10-05 体检发现不符合，已在 `技术方案.md` 中修正。）
- [x] 开发计划只更新任务状态和进度百分比，不记录过程日志。
- [ ] 重大技术选择写明来源、原因和限制。
- [ ] 每次验收后同步变更记录。（2026-10-02 之后漏记，已在 `变更记录.md` 中补上。）
