# LumeKit 浮层设计规范

> **已归档（2026-10-11），仅作历史参考。**
> 设计基线已并入 `开发文档/技术方案.md` 第 5 节，设计验收项已并入 `开发文档/验收标准.md` 第 8 节。

## 0. 引用项目的托盘右键菜单结构

引用项目 DeskBox 的托盘右键菜单采用下面这条结构：

```text
Windows 托盘图标
        ↓
H.NotifyIcon 负责接收右键
        ↓
WinUI MenuFlyout 负责显示菜单
        ↓
MenuFlyoutItem 负责文字、图标和点击动作
```

每一层的作用很简单：

1. **Windows 托盘图标**：用户实际点击的入口。
2. **H.NotifyIcon**：把 Windows 托盘的右键操作交给应用。
3. **WinUI MenuFlyout**：负责弹出菜单、分组和分隔线。
4. **MenuFlyoutItem**：负责每一行的文字、图标和点击后的功能。

LumeKit 后续的托盘右键菜单沿用这套结构，再套用本规范中的统一字体、圆角、间距和主题样式。

## 1. 目的

这份规范统一 LumeKit 的三类浮层：

1. 悬浮通知
2. 托盘左键快速面板
3. 托盘右键命令菜单

三者使用同一套视觉语言，但不强行做成同一种界面。

- 悬浮通知负责告诉用户发生了什么。
- 托盘左键面板负责快速查看和控制。
- 托盘右键菜单负责执行明确命令。

## 2. 参考来源

本规范参考：

- `开发文档/引用项目/DeskBox-main`

- `UI设计规范.md`

引用项目的主要设计参数：

- 菜单字号：`13`
- 菜单最小行高：`36`
- 菜单项内边距：`10,8,10,8`
- 浮层圆角：`8`
- 页面内常用圆角：`4`
- 常用间距：`4 / 8 / 12 / 16`
- 轻量悬停背景：约 `8%` 透明度

## 3. 总体规则

### 3.1 统一的视觉感觉

所有浮层都应满足：

- 使用 WinUI 原生主题资源。
- 背景跟随系统明暗主题。
- 文字使用 `Segoe UI Variable`；菜单可保留引用项目的中文字体兜底。
- 浮层使用 `8` 圆角。
- 页面内的小行、小按钮使用 `4` 或 `6` 圆角。
- 不使用厚重阴影。
- 不额外使用鲜艳的大面积品牌色。
- 重点状态优先用图标、透明度、边框和选中状态表达。
- 长文字使用省略号，不撑破浮层。

### 3.2 统一的间距

统一使用 `4` 的倍数：

| 用途 | 参数 |
| --- | ---: |
| 最小间距 | `4` |
| 图标和文字之间 | `8` |
| 同一行控件之间 | `8` |
| 小区块之间 | `12` |
| 浮层内容左右留白 | `16` |
| 大区块之间 | `16` 或 `24` |

### 3.3 统一的文字层级

| 用途 | 字号 | 字重 |
| --- | ---: | --- |
| 浮层标题 | `14` | SemiBold |
| 主要内容 | `13` 或 `14` | Regular |
| 状态值、重点信息 | `13` 或 `14` | SemiBold |
| 辅助说明 | `11` 或 `12` | Regular |
| 托盘命令菜单 | `13` | Regular |

### 3.4 统一的状态

三类浮层都要支持：

- 默认状态
- 悬停状态
- 按下状态
- 禁用状态
- 当前选中或当前生效状态
- 深色主题
- 浅色主题
- 高对比度主题的基本可读性

悬停背景使用浅色的系统中性色，不单独制作一套彩色按钮。

## 4. 场景一：悬浮通知

### 4.1 用途

用于显示：

- 音频输入输出切换
- 蓝牙设备连接和断开
- 自动亮度、主题或节能状态变化
- 自动化执行结果
- 按键或状态指示器变化

通知默认只负责传达信息。只有用户确实需要马上处理时，才增加操作按钮。

### 4.2 尺寸方案

沿用当前项目已有的通知尺寸，并纳入公共规范：

| 类型 | 宽度 | 高度 | 适用内容 |
| --- | ---: | ---: | --- |
| 标准通知 | `600` | `110` | 常规音频、设备和状态提示 |
| 紧凑通知 | `420` | `110` | 一行短提示 |
| 自动化通知 | `600` | `130` | 标题加多行执行结果 |
| 合并通知 | `600` | `180` | 主通知加短时间内追加的内容 |
| 快捷键通知 | `400` | `110` | 单个快捷键或按键状态 |

后续改通知尺寸，优先修改 `NotificationLayoutProfiles`，不要在各个调用处单独改宽高。

### 4.3 外观

- 浮层圆角：`8`
- 内容左右留白：`16`
- 普通图标区域：约 `30 x 30`
- 普通图标字号：约 `18`
- 合并通知图标区域：约 `34 x 34`
- 合并通知图标字号：约 `20`
- 标准正文：`13`
- 自动化明细：`13`
- 主要文字：不透明
- 状态文字：约 `68%` 不透明度
- 图标和正文间距：`8` 到 `12`

图标优先使用 `Segoe Fluent Icons` 或项目现有图标资源，不使用表情符号作为正式图标。

### 4.4 动画

沿用当前项目的动画节奏：

| 动作 | 参数 |
| --- | ---: |
| 显示动画 | `300ms` |
| 隐藏动画 | `200ms` |
| 内容尺寸变化 | `160ms` |
| 自动隐藏 | `2500ms` |
| 入场纵向位移 | `30px` |
| 动画刷新 | `16ms` |
| 缓动力度 | `3` |

动画要求：

- 从底部向上轻微进入。
- 同时渐显。
- 隐藏时向下轻微退出并渐隐。
- 不做弹跳、旋转和大幅缩放。
- 用户正在操作托盘面板时，可以按设置隐藏悬浮通知。

### 4.5 内容规则

标准通知推荐结构：

```text
[图标] 主要信息                         状态值
```

自动化通知推荐结构：

```text
[图标] 标题
       执行结果或明细
```

合并通知推荐结构：

```text
[图标] 主通知                             状态值
       追加内容 1
       追加内容 2
```

通知正文尽量控制在一到两行。超过两行时，优先使用合并通知或自动化通知布局。

## 5. 场景二：托盘左键快速面板

### 5.1 用途

左键托盘图标打开快速面板，用于：

- 查看当前音频输入输出状态
- 快速切换设备
- 查看快捷键
- 执行高频操作

它是“快速控制面板”，不是设置页面，也不是命令菜单。

### 5.2 尺寸方案

沿用当前项目托盘快速面板的宽度和高度：

| 参数 | 数值 |
| --- | ---: |
| 默认宽度 | `650` |
| 默认高度 | `400` |
| 最小高度 | `260` |
| 屏幕边缘安全距离 | `10` |
| 面板圆角 | `8` |

如果内容超出高度，使用纵向滚动，不把窗口无限拉长。

### 5.3 标题区

标题区使用：

| 参数 | 数值 |
| --- | ---: |
| 标题字号 | `14` |
| 标题字重 | SemiBold |
| 辅助说明字号 | `11` |
| 标题区内边距 | `40,10,10,10` |
| 标题和辅助说明间距 | `8` |
| 分割线高度 | `1` |
| 分割线上方留白 | `4` |
| 分割线下方留白 | `6` |

标题要直接说清楚当前面板是什么，例如“音频管理”。

### 5.4 设备行

每一行按下面的顺序组织：

```text
[状态点] [设备图标] 设备名称                         快捷键
```

参数：

| 参数 | 数值 |
| --- | ---: |
| 行文字号 | `12` |
| 快捷键字号 | `12` |
| 行内边距 | `6,5,6,5` |
| 行外边距 | `4,2,4,2` |
| 行圆角 | `6` |
| 状态点半径 | `4` |
| 状态点列宽 | `20` |
| 图标列宽 | `30` |
| 名称列宽 | `170` |
| 快捷键列宽 | `220` |
| 快捷键列最小宽度 | `120` |
| 行间距 | `0` |

### 5.5 设备行状态

- 当前连接或当前使用的设备：显示绿色状态点。
- 未连接设备：状态点透明，不显示灰色圆点。
- 鼠标移入：显示约 `8%` 透明度的中性色背景。
- 鼠标移出：恢复透明背景。
- 点击设备：立即执行连接、断开或切换。
- 设备名称过长：显示省略号。
- 快捷键为空：显示 `--`。

快捷键徽章：

- 背景使用约 `8%` 透明度的中性色。
- 圆角：`6`
- 内边距：`12,4,12,4`
- 不使用鲜艳背景色。

### 5.6 打开和关闭

- 左键托盘图标：打开或关闭快速面板。
- 面板显示在鼠标附近，并自动避开屏幕边缘。
- 点击面板外部：关闭面板。
- 再次点击托盘图标：关闭面板。
- 面板显示期间，按设置决定是否隐藏悬浮通知。
- 不出现在任务栏窗口切换列表中。

## 6. 场景三：托盘右键命令菜单

### 6.1 用途

右键托盘图标打开命令菜单，用于：

- 打开主界面
- 打开通知设置
- 打开音频设置
- 打开相关目录或工具
- 重启应用
- 退出应用

命令菜单只放“动作”，不放复杂状态展示。

### 6.2 推荐结构

菜单建议按功能分组：

```text
打开主界面
----------------
快速切换或常用动作
打开通知设置
打开音频设置
----------------
打开相关目录
----------------
重启
退出
```

具体项目可以根据实际功能删减，但分组逻辑保持不变。

### 6.3 尺寸和样式

引用项目的菜单参数作为统一基准：

| 参数 | 数值 |
| --- | ---: |
| 菜单项最小高度 | `36` |
| 菜单项字号 | `13` |
| 菜单项内边距 | `10,8,10,8` |
| 菜单上下留白 | `4` |
| 菜单字体 | `Microsoft YaHei UI, Segoe UI Variable, Segoe UI` |
| 菜单圆角 | `8` |
| 图标和文字间距 | 采用 WinUI 默认间距 |
| 分隔线左右留白 | `8` |

菜单宽度建议：

- 普通命令菜单：`176`
- 预留菜单外框宽度：约 `192`
- 中文命令较长时，以最长命令完整显示为准。

当前项目已有的 `92` 宽度、`30` 行高菜单仅适合作为旧版固定三行菜单，不作为新的公共标准。

### 6.4 菜单内容

每个菜单项都应有：

- 清楚的动作名称
- 熟悉的图标
- 明确的点击结果
- 必要时的禁用状态

推荐图标规则：

- 打开主界面：窗口或主页图标
- 设置：齿轮图标
- 打开目录：文件夹图标
- 重启：刷新图标
- 退出：叉号图标
- 连接或切换：设备、箭头或音频图标

图标优先使用 WinUI 的 `SymbolIcon` 或 `Segoe Fluent Icons`，不手工画一套风格不一致的图标。

### 6.5 交互规则

- 右键托盘图标：打开命令菜单。
- 点击菜单项后先关闭菜单，再执行动作。
- 打开设置、主窗口等窗口动作，不阻塞菜单关闭。
- 不在菜单中放需要连续编辑的输入框。
- 不在菜单中显示大段说明文字。
- 不把通知卡片直接嵌入命令菜单。
- 菜单内容较多时，用分隔线分组，不使用多层嵌套。
- 菜单打开位置要靠近托盘图标，并自动避开屏幕边缘。

### 6.6 危险操作

“退出”“重启”等操作放在菜单底部。

- 退出可以使用普通菜单项。
- 清除数据、恢复默认等不可逆操作不能直接放在托盘菜单里。
- 需要确认的危险操作，应打开确认对话框。

## 7. 三种浮层的区别

| 项目 | 悬浮通知 | 托盘左键快速面板 | 托盘右键命令菜单 |
| --- | --- | --- | --- |
| 主要目的 | 告知 | 查看和控制 | 执行命令 |
| 默认尺寸 | `600 x 110` | `650 x 400` | 约 `192` 宽 |
| 圆角 | `8` | `8` | `8` |
| 内容密度 | 低 | 中 | 高 |
| 是否自动消失 | 是 | 否，点击外部关闭 | 是，点击后关闭 |
| 是否支持滚动 | 一般不支持 | 支持纵向滚动 | 尽量不需要 |
| 主要文字 | `13` | `12` | `13` |
| 标题 | 可选 | 必须有 | 不单独设置大标题 |
| 操作数量 | 少量 | 多个快速操作 | 多个命令 |
| 适合放状态 | 是 | 是 | 少量，不作为主体 |

## 8. 统一入口建议

后续把公共参数集中到以下位置：

### 8.1 全局浮层参数

建议新增统一入口，集中保存：

- 浮层圆角
- 浮层内边距
- 浮层边缘安全距离
- 主文字字号
- 辅助文字字号
- 图标和文字间距
- 悬停背景透明度
- 分割线高度
- 分割线颜色
- 浮层显示和隐藏动画

### 8.2 现有入口继续保留

- 通知尺寸：`Contracts/Services/NotificationLayoutProfiles.cs`
- 通知动画：`Views/Windows/NotificationWindow.xaml.cs`
- 托盘快速面板：`Views/Windows/TrayQuickPanelWindow.xaml.cs`
- 托盘命令菜单：后续统一迁移到公共浮层参数入口
- 菜单资源：`Styles/DeskBoxMenuResources.xaml`

### 8.3 修改顺序

以后需要调整浮层时，按这个顺序：

1. 先改公共浮层参数。
2. 再改具体场景的尺寸参数。
3. 最后才处理某个特殊内容的局部例外。

不要在多个窗口里分别写相同的圆角、字号和间距。

## 9. 设计验收标准

完成任意一种浮层后，至少检查：

- 深色和浅色主题都能看清。
- 中文长文本不会被截断得难以理解。
- 菜单项不会因为文字变长而互相挤压。
- 浮层不会跑出屏幕工作区。
- 点击外部能正确关闭需要关闭的浮层。
- 通知不会挡住托盘快速面板，除非用户明确允许。
- 悬停和按下状态足够明显，但不刺眼。
- 三种浮层看起来属于同一个 LumeKit。
- 关键尺寸都能从统一入口调整。

## 10. 当前结论

LumeKit 采用：

> 一套浮层视觉语言，三种场景分别布局。

统一的部分：

- 字体
- 颜色
- 圆角
- 间距
- 图标
- 分隔线
- 悬停和按下状态
- 屏幕边缘避让

分别处理的部分：

- 通知的自动消失和动画
- 快速面板的设备列表和点击切换
- 命令菜单的分组和命令执行

这套方案作为后续悬浮通知、托盘左键面板和托盘右键菜单的公共设计基线。
