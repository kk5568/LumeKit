## 本次内容

### 图标修复

- 使用 `BluetoothAudioReceiver/Assets/speakericon1.png` 作为 LU 图标源。
- 重新生成多尺寸 ICO，包含：
  - `16×16`
  - `32×32`
  - `48×48`
  - `256×256`
- 更新：
  - `BluetoothAudioReceiver/Assets/speakericon3_32x32.ico`
  - `BluetoothAudioReceiver/Assets/speakericon3_256x256.ico`
- 保留原图透明区域，不额外填充蓝色、黑色或其他背景。
- 保留窗口、任务栏、托盘现有引用方式，不新增图标调用路径。

### 17.0 优化

- 自动化统一为观察层、决策层、执行层。
- 保留 `AutomationTriggerBus` 作为观察层到决策层的事件入口。
- 删除 `MainlineBus`。
- 删除状态捕获、状态恢复、回滚和 Trace 相关实现。
- 保留自动化规则、触发器、条件、动作和音频、主题、亮度、电源能力。

### 启动页面清理

- 删除系统清单中的 `uap:SplashScreen`。
- 删除程序内 `SplashScreenPage` 及其启动等待逻辑。
- 保留窗口图标和托盘图标配置。

## 验证结果

- Debug x64 编译通过。
- 编译结果：`0` 个错误，`98` 个警告。
- 两个任务栏/窗口 ICO 均包含 4 个尺寸图层。
- Debug 和 Release 包图标资源尺寸已按清单要求生成。

## 测试说明

Windows 可能缓存旧的任务栏图标。测试本版本时，应先卸载旧 Debug 包，重新安装当前构建结果，再重新固定任务栏图标。
